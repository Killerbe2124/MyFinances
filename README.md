# MyFinances

Telegram-бот для учёта личных финансов на Go с хранением данных в SQLite.

## Возможности

- **Умный парсинг текста** — понимает естественный язык: `450 продукты`, `такси 1200 вчера`, `85,5 кофе`
- **Автоматическое определение категорий** — 12 встроенных категорий с распознаванием по ключевым словам
- **Гибкие форматы сумм** — `450`, `85,5`, `1.5к`, `1 500`, `1_500`
- **Поддержка дат** — относительные (`вчера`, `позавчера`) и абсолютные (`25.09`, `25.09.2025`)
- **Множественные траты** — можно указать несколько трат в одном сообщении через запятую, точку с запятой или перенос строки
- **Статистика** — команда `/stats` показывает распределение трат по категориям с процентами
- **История** — команда `/list` выводит последние 10 записей
- **Локальное хранение** — SQLite база данных, данные не теряются при перезапуске
- **Мультипользовательский режим** — каждый пользователь Telegram имеет изолированную базу трат

## Быстрый старт

### Требования

- Go 1.21 или выше
- Telegram-токен от [@BotFather](https://t.me/BotFather)

### Установка

```bash
git clone https://github.com/ВАШ_НИК/MyFinances.git
cd MyFinances
go mod tidy
```

### Настройка

1. Создайте файл `.env` в корне проекта:

```bash
cp .env.example .env
```

2. Откройте `.env` и вставьте ваш токен:

```env
BOT_TOKEN=123456789:AAHx_ваш_токен_от_BotFather
DB_PATH=bot.db
```

Получить токен можно у [@BotFather](https://t.me/BotFather) командой `/mybots`.

### Запуск

```bash
go run main.go
```

После успешного запуска вы увидите:
```
2026/01/15 21:30:00 Бот авторизован как @MyFinancesBot
```

## Использование

### Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Справка и приветствие |
| `/stats` | Статистика за текущий месяц |
| `/list` | Последние 10 трат |

### Формат сообщений

Просто напишите боту трату в свободной форме:

```
450 продукты
1200 такси вчера
85,5 кофе
1.5к аренда
500 подарок 25.09
200 ремонт машины
```

### Примеры работы

**Ввод:**
```
450 продукты
```

**Ответ:**
```
✅ 4,50 ₽ → Продукты
📅 29.09.2026
```

**Ввод:**
```
1200 такси вчера
```

**Ответ:**
```
✅ 12,00 ₽ → Транспорт
📅 28.09.2026
```

**Ввод:**
```
100 купил вафли для кота
```

**Ответ:**
```
✅ 1,00 ₽ → Другое
💬 купил вафли для кота
📅 29.09.2026
```

**Несколько трат:**
```
450 продукты, 1200 такси; 85,5 кофе
```

Бот разберёт и запишет три отдельные траты.

## Переменные окружения

Все настройки бота хранятся в файле `.env`:

| Переменная | Описание | Пример |
|------------|----------|--------|
| `BOT_TOKEN` | Токен бота от BotFather | `123456789:AAHx...` |
| `DB_PATH` | Путь к файлу базы данных | `bot.db` |

Файл `.env` добавлен в `.gitignore` и **никогда не попадает в репозиторий**.

## Технологии

- **Go 1.21+** — язык программирования
- **Telegram Bot API** (`go-telegram-bot-api/v5`) — взаимодействие с Telegram
- **SQLite** (`modernc.org/sqlite`) — локальная база данных на чистом Go
- **godotenv** (`github.com/joho/godotenv`) — загрузка переменных окружения из .env
- **Регулярные выражения** — парсинг сумм и дат

## Категории

Бот автоматически определяет категорию по ключевым словам:

| Категория | Примеры слов |
|-----------|--------------|
| Продукты | магазин, пятёрочка, хлеб, молоко |
| Кафе и рестораны | кофе, обед, пицца, суши, кфс, макдональдс |
| Транспорт | такси, метро, бензин, билет |
| Жильё | аренда, коммуналка, ипотека |
| Связь и интернет | телефон, тариф, симка |
| Здоровье | аптека, врач, лекарства |
| Развлечения | кино, театр, игры |
| Одежда | куртка, джинсы, обувь |
| Подписки | Netflix, YouTube, Кинопоиск |
| Подарки | подарок |
| Образование | курс, книга, учебник |
| Дом и быт | IKEA, уборка, посуда |

Если категория не найдена и слов ≤ 2 — создаётся новая категория. Иначе — запись попадает в «Другое» с комментарием.

## Безопасность

- **Токен бота хранится только в `.env`** — файл добавлен в `.gitignore` и не попадает в репозиторий
- **База данных локальна** — файл `bot.db` также исключён из Git
- **Все данные на вашем устройстве** — никаких внешних сервисов и облаков

### Что делать, если токен попал в Git

Если вы случайно закоммитили `.env` с токеном:

1. Отозовите токен через [@BotFather](https://t.me/BotFather) командой `/revoke`
2. Получите новый токен
3. Обновите `.env` и добавьте его в `.gitignore`
4. Удалите `.env` из истории Git:
   ```bash
   git rm --cached .env
   git commit -m "Remove .env from repository"
   ```
